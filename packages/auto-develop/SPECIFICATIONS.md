# @mst/auto-develop

生成物。`vp run guard:fix` が `specs/` の仕様担保テストから再生成する。手で編集しない。

## コミットステータスは PR の現在の入力に対する結果を表す

[`specs/commit-status.spec.ts`](specs/commit-status.spec.ts)

- base はブランチ名の変化で入力の変更とみなす
- base ブランチが同名のまま前進しても入力は変わっていない
- head はコミット SHA の変化で入力の変更とみなす
- 直近の実効レビューが変更要求ならステータスは error になる
- 直近の実効レビューが承認ならステータスは success になる
- 実効レビューが一度も無ければステータスは success へ倒す
- コメントのみのレビューは判定に数えない
- 代理ログイン以外が出したレビューは判定に数えない

## エンジンは PR ごとの仮想端末セッションで動く

[`specs/engine-session.spec.ts`](specs/engine-session.spec.ts)

- セッション名は PR 番号から決まる
- 権限の確認を外す指定は明示したときだけ引数に現れる
- 書き込みを許すディレクトリはリポジトリルートと共通 git ディレクトリに限る
- 作業ディレクトリと同じルートは許可対象から外す
- 起動プロンプトに diff を埋め込まない
- 起動プロンプトは実行コンテキストの場所だけを伝える
- エンジンの認証失効は出力の文言から見分ける
- 通常の失敗出力は認証失効と見分けられる

## PR ごとのレーンが自動応答の同時実行を 1 件に抑える

[`specs/job-lane.spec.ts`](specs/job-lane.spec.ts)

- レーン名は PR 番号から決まる
- 除外指定は対象指定に勝つ
- 対象指定が空なら PR レーンをすべて受け入れる
- 同じレーンで実行中の別ジョブは受け付けずに捨てる
- 後続受付は待機中の 1 件を最新の内容へ差し替える
- 前のプロセスが残したスナップショットを読み戻さない

## GitHub の credential はリレーの発行口だけに渡る

[`specs/relay-credential.spec.ts`](specs/relay-credential.spec.ts)

- 契約したオリジン以外へは credential を出さない
- GitHub token を解決できなければ恒久エラーで止まる
- 購読にはリレーが発行した短寿命の credential を提示する
- 失効まで余裕があれば GitHub の証明をやり直さない
- 失効が近づけば発行し直す
