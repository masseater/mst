# @mst/auto-develop

## このパッケージが守るもの

人が起動しなくても、pull request へのレビューと指摘への応答が回り続ける。

回り続けるために、レビューする側（reviewer）と指摘に応答する側（author）、その 2 つへ GitHub のイベントを届ける中継サーバー、そして両者が共有するイベント封筒の語彙を、この 1 つのパッケージが持つ。別々に配ると封筒の語彙が 2 箇所で進化して食い違うため、境界は内部の型に留める。

## 規約

- IF: 接続先・資格情報・許可リポジトリを実装から参照する; THEN
  - MUST: 設定注入で受け取り、欠けていれば起動時に失敗させる
  - PROHIBIT: 特定環境のアドレスや識別子を定数として置く
    - 定数に環境が焼き込まれると、このパッケージを別環境で立てられなくなる
- IF: 状態を永続化する; THEN
  - MUST: 永続化の境界を差し替え可能に切り、既定は外部 DB なしで動くインメモリ実装にする
    - 再起動時の取りこぼしは、クライアント側が GitHub の現在状態から再導出して巻き取る
