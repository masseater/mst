# @mst/agentic-documents

What each published version changes for the packages that install it, and for the agents that load the skills shipped beside this file.

## 0.0.0

- A `check` CLI that reads the AI-facing documents of a repository and reports where they stop matching it: references that point at nothing, and shapes a machine cannot follow.
- `--write` repairs what is decided by the repository itself, so the generated parts of those documents are not maintained by hand.
