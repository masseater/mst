# website

## この場所が守るもの

ツールチェーンの開発サーバーとビルドが、実際に動く対象を持っている状態。

このリポジトリが整備しているのはリポジトリ運用の仕組みであって、この場所で作るものが成果物なのではない。ここは、開発サーバーとビルドの経路が生きていることを確かめるために存在する。

## 扱い

- IF: 足場を組む道具が生成したものに問題が出た; THEN
  - PROHIBIT: 独自の設計へ書き換える
  - MUST: 道具の側の課題を先に調べる
- IF: lint ルールがこの場所のコードに当たった; THEN MUST: コードの側を直す
  - 生成物をそのまま使う方針と、ルールに従うことは衝突しない。ルールの側が新しく、コードの側が古いだけである
- IF: この場所に固有の規約が要ると感じた; THEN MUST: それがリポジトリ全体に効く規約でないかを先に確かめる
  - 全体に効くならルートの規範文書へ書く
