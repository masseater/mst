# 0027. catalog は共有されるバージョンだけを持つ

- ステータス: Accepted
- 日付: 2026-08-11

## 文脈

これまでの規約は「依存のバージョンを宣言するなら catalog に集約する」だった。実際の catalog には、1 つのワークスペースしか使わないエントリが 14 件あった（`knip`、`@opentelemetry/*` 5 件、remark 系 4 件、`jsonc-parser`、`oxc-parser`、`oxfmt`）。

catalog の価値は「複数のワークスペースが同じバージョンを共有している」ことを 1 か所で宣言することにある。共有していないバージョンが混ざると、catalog を読んでも「どの依存が揃っているべきか」が読めなくなり、単に宣言場所が 2 段になるだけになる。逆の形も残っていた。共有すべきバージョンを各ワークスペースが直接書き写すと、片方だけ上げた瞬間に黙って割れる。

どちらの形も機械で判定できるのに、規約の文面だけがそれを支えていた。

## 決定

**`dont-review-it check` に依存宣言の検査を足す。** `pnpm-workspace.yaml` の存在を pnpm 使用の印として、無ければ何も検査しない。error は 3 つ。

- 1 つのマニフェストしか使わない catalog エントリ。直し方はバージョンをそのマニフェストへ書き、エントリを消すことに一意に決まる
- catalog が持つバージョンをマニフェストが直接書き写した宣言。直し方は `catalog:` 参照への置換に一意に決まる
- 複数のマニフェストが catalog の外で繰り返す同一バージョン。直し方は catalog への集約に一意に決まる

**バージョンが食い違う宣言は warning にする。** どちらへ揃えるかは判断であり、直し方が一意に決まらない問いを error にしない、というルールの境界の判断をそのまま適用する。warning は `warning:` を先頭に付けて出し、終了コードに数えない。

**境界を 3 つ引いた。**

- overrides が `catalog:` で参照するエントリは単一使用でも報告しない。`vite` のエイリアス配線（[EDR 0001](0001-adopt-vite-plus-as-the-toolchain.md)）は overrides が実際の参照者であり、inline の指示が誤りになる
- 何も使っていない catalog エントリは報告しない。未使用の検出は knip が持ち、同じ違反を 2 経路から報告しない
- `workspace:` / `link:` / `file:` の指定子は数えない。catalog が持てる形ではない

**同一 run で 1 つの依存に矛盾する指示を出さない。** 単一使用と判定した catalog エントリは、その run の「直書きを `catalog:` 参照に置換しろ」の判定から外す。「エントリを消せ」と「エントリを参照しろ」が同時に並ぶと、どちらを先に信じるかが判断になってしまう。除外で報告されずに残った違反は、指示どおり直した後の次の run が一意な指示として報告する。検査が保証するのは 1 run での全列挙ではなく、直すたびに次の指示へ収束することである。

**`catalogMode: prefer` は変えない。** prefer が自動で catalog に書くのは既にエントリがある依存の追加時だけで、新規依存を勝手に catalog へ入れるのは strict の挙動である。単一使用エントリの禁止と衝突しない。

## 影響

**規約が実態と一致した。** `AGENTS.md` の宣言規則は「複数のワークスペースが使うなら catalog、1 つだけなら直書き」に書き換え、14 件のエントリを使用側のマニフェストへ inline した。lockfile の解決結果は変わらず、`vp why` の単一インスタンスも保たれている。

**check に初めて warning が入った。** これまで check の報告はすべて非ゼロで落ちていた。「報告だけ出してゼロで終わる検査を残さない」（[EDR 0026](0026-give-the-checks-one-entry-that-fails.md)）は error の規範として残り、warning は直し方が一意に決まらない事象だけに限る。

**ワークスペースの列挙は `dir/*` と直書きだけを解釈する。** `**` や `!` の否定はパターンごと読み飛ばす。pnpm の glob 全部を再実装すると、既製の解決器と食い違ったときにどちらが正かという別の問題を抱える。読み飛ばした分は検査対象が減るだけで、誤報告にはならない。
